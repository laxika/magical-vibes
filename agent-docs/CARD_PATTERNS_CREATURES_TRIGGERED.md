# Card Patterns: Triggered Creatures

> A row that still writes a "whenever [a player] casts a spell" ability as `SpellCastTriggerEffect(filter, effects, …)`
> (or a factory such as `.nth(n, …)` / `.withIntervening(…)`) is shorthand: author it as the cast trigger's filter and the
> ability's effects, `addTrigger(Triggers.youCastSpell().withFilter(filter)[.nthThisTurn(n)…][, TriggerOptions…], effects…)`
> (`.anySpell()` for a null filter), with "you may" a `MayEffect`, a mana cost a `MayPayManaEffect` and a target filter a
> target group. See `SpellCastTriggerEffect` in `EFFECTS_INDEX.md`; the record itself is built by the engine.

> `STATIC` in this file means a static ability (CR 113.3d), written `addStaticEffect(e)`, or
> `target(f).addStaticEffect(e)` for an Aura's enchant ability. It functions from the zones its effect's
> rule names (`CardEffect.staticAbilityZones()`): the battlefield, the stack for kicker, buyback, gift,
> "can't be countered" and "costs less to cast", the hand for splice, mulligan-time actions and opening-hand
> actions (`MayEffect(PregameChoiceEffect)`), and the graveyard for dredge. "Enters with" and "as this enters"
> abilities (CR 614.1c) are static abilities too, never `Triggers.enters(ObjectRelation.THIS)`. An ability that states its
> zones, such as Eminence, is written `addStaticEffect(AbilityZones.of(...), e)`. In a token's or a
> copy's ability list it is `StaticAbility.of(e)`, next to `LegacySlots.triggered(EffectSlot.X, e)` for
> a trigger. Readers use `getStaticEffects()`. There is no `EffectSlot.STATIC`.

- Damage to an opponent, combat or noncombat: `r/ReefPirates.java` uses `Triggers.dealsDamageToOpponent()` with `MillEffect(1, TARGET_PLAYER)`. Both damage collectors supply the damaged opponent; damage to the source's controller does not trigger.
- Combat damage → untap your creatures and add a combat: `p/PortRazer.java` uses `Triggers.dealsCombatDamageToPlayer()` with `UntapPermanentsEffect(CONTROLLED, PermanentIsCreaturePredicate())` and `AdditionalCombatPhaseEffect(1)`; pair with `CantAttackPlayerAlreadyAttackedThisTurnEffect` for the source's player-only attack restriction.
- One or more subtype-matching creatures deal combat or noncombat damage to an opponent: use `Triggers.creaturesYouControlDealDamageToOpponent().withFilter(new PermanentHasSubtypePredicate(...))` with the plain effect. The dedicated damage-event batch fires once per opponent dealt damage even when multiple matching creatures deal damage simultaneously (Malcolm, Keen-Eyed Navigator). With a predicate, noncreature permanents and spells of that type (a Kindred Pirate spell, including text-changed types) also count as dealers.
- One or more goaded creatures deal combat damage to an opponent: use `Triggers.goadedCreaturesDealCombatDamageToOpponent()` with the effect to run. The dedicated combat-damage batch checks active goad requirements across all creatures and fires once per damaged opponent (Puppet Master, String Puller).
- Whenever a goaded creature attacks, have that attacker deal damage to its controller: use `Triggers.creatureAttacks().withFilter(PermanentIsGoadedPredicate), TargetCreatureDealsDamageToControllerEffect(amount)`; the attack collector carries the attacking creature as the implicit non-targeting target (Vengeful Ancestor).
- Any-player library shuffles: `Triggers.playerShufflesLibrary()` uses the same shuffle event and remembers the shuffling player, including the source controller (Psychogenic Probe).
- Opponent library shuffles: `LibraryShuffleHelper` queues `Triggers.opponentShufflesLibrary()` effects as normal non-targeting triggers. A `MayEffect` choice happens on resolution, not while the shuffle instruction is still resolving (Cosi's Trickster, Psychic Surgery).
- End-of-combat control of current blockers: `t/TheWretched.java` uses `Triggers.endOfCombat()` with source-relative `GainControlOfAllPermanentsMatchingEffect` and a source-linked duration. Combat assignments remain available until the step ends.
