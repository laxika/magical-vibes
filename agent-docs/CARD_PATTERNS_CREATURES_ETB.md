# Card Patterns: Vanilla, Keyword & ETB Creatures

All paths relative to `cards/`.

For an ETB that free-casts an instant from your graveyard, use
`CastTargetInstantOrSorceryFromGraveyardEffect(CONTROLLERS_GRAVEYARD, true, true,
CardTypePredicate(INSTANT))` as in `t/TorrentialGearhulk.java`.

Echo ETB pattern: `k/KeldonChampion.java` combines `DealDamageToTargetPlayerOrPlaneswalkerEffect(3)` with `RegisterEchoAtNextUpkeepEffect("{2}{R}{R}")`; the registrar creates a one-shot echo trigger for the source permanent's current controller.

## Vanilla creatures (empty body, all from Scryfall)

Reference: `a/AirElemental.java` — no constructor code needed.

## Keyword creatures (keywords from Scryfall, empty body)

| Pattern | Reference | Notes |
|---------|-----------|-------|
| Tribute + conditional ETB | `o/Ornitharch.java` | STATIC `TributeEffect(N)` records the opponent's as-enters choice; wrap the conditional ETB in `TributeNotPaidEffect` so it is dropped when the full counter amount entered on the creature |
| Infect creature | `b/BlackcleaveGoblin.java` | Haste + Infect auto-loaded from Scryfall. Infect deals damage as -1/-1 counters to creatures and poison counters to players. |
| Infect + damage replacement | `p/PhyrexianHydra.java` | Infect from Scryfall + STATIC PreventDamageAndAddMinusCountersEffect. Prevents all damage to self and puts -1/-1 counters instead. |
| Intimidate creature + activated ability | `g/GethLordOfTheVault.java` | Intimidate from Scryfall + X-cost graveyard-targeting activated ability. PutCardFromOpponentGraveyardOntoBattlefieldEffect(tapped=true) |
| ETB grants a keyword to another target permanent for as long as you control the source | `a/AegisAngel.java` | ON_ENTER_BATTLEFIELD `GrantKeywordEffect(Set.of(INDESTRUCTIBLE), TARGET, another, GrantDuration.WHILE_SOURCE_ON_BATTLEFIELD, null)` with `another = PermanentNotPredicate(PermanentIsSourceCardPredicate)` used BOTH as the card-level `PermanentPredicateTargetFilter` (EntersTriggerTarget pipeline) and as the effect filter. The grant is a floating layer-6 effect keyed to the source — it survives cleanup and ends when the Angel leaves the battlefield or changes controller |
| Keyword creature + shuffle-into-library replacement | `b/BlightsteelColossus.java` | Keywords (infect, trample, indestructible) auto-loaded from Scryfall + STATIC `ShuffleIntoLibraryReplacementEffect`. Replacement effect: when put into graveyard from anywhere, shuffled into owner's library instead. Also used by `l/LegacyWeapon.java`. |
| Keyword creature + exile-with-egg-counters death replacement | `d/DarigaazReincarnated.java` | Keywords (flying, trample, haste) auto-loaded from Scryfall + STATIC `ExileWithEggCountersInsteadOfDyingEffect(3)`. "If would die, instead exile with 3 egg counters." Upkeep trigger removes 1 counter per owner's upkeep; returns to battlefield when last counter removed. Counter tracking via `GameData.exiledCardEggCounters`. |
| Creature + bottom-of-library death replacement | `n/NissasChosen.java` | STATIC `PutOnBottomOfLibraryInsteadOfDyingEffect`; when the creature would die, it goes to the bottom of its owner's library instead of the graveyard. |
| Can't be countered + keyword + ability | `t/ThrunTheLastTroll.java` | STATIC `CantBeCounteredEffect` + hexproof from Scryfall + `{1}{G}` RegenerateEffect activated ability. Checked by `GameQueryService.isUncounterable()`. |
| Alternate casting cost (sacrifice + life) | `d/DemonOfDeathsGate.java` | `addCastingOption(new AlternateHandCast(List.of(new LifeCastingCost(N), new SacrificePermanentsCost(M, predicate))))` — "You may pay N life and sacrifice M [matching] creatures rather than pay this spell's mana cost." Frontend sends `alternateCostSacrificePermanentIds` in PlayCardRequest. Keywords (flying, trample) auto-loaded from Scryfall. |
| Emerge (sacrifice creature; mana cost reduced by its MV) | `a/AbundantMaw.java` / `d/DistendedMindbender.java` / `e/ElderDeepFiend.java` / `w/WretchedGryff.java` | `addCastingOption(new AlternateHandCast(List.of(new ManaCastingCost("{cost}"), new SacrificePermanentsCost(1, PermanentIsCreaturePredicate())), true))` — emerge cost; `true` = reduce generic by sacrificed creature's mana value. Wretched Gryff: `ON_SELF_CAST` `DrawCardEffect(1)`. Distended: `ON_SELF_CAST` dual-filter hand discard via `ChooseTwoFilteredCardsFromTargetHandToDiscardEffect`. Elder Deep-Fiend: Flash + `ON_SELF_CAST` tap up to 4 via `target(PermanentTruePredicate, 0, 4)` + `TapPermanentsEffect(TARGET)` |
| Alternate casting cost (mana + tap artifact) | `z/ZahidDjinnOfTheLamp.java` | `addCastingOption(new AlternateHandCast(List.of(new ManaCastingCost("{3}{U}"), new TapUntappedPermanentsCost(1, new PermanentIsArtifactPredicate()))))` — "You may pay {3}{U} and tap an untapped artifact you control rather than pay this spell's mana cost." Frontend sends tapped artifact ID in `alternateCostSacrificePermanentIds`. Keywords (flying) auto-loaded from Scryfall. |
| Conditional free cast with flash | `q/QasaliAmbusher.java` | `addCastingOption(new AlternateHandCast(List.of(), Condition, grantsFlash=true))` — free cast (empty cost list) gated by an availability `Condition`; `grantsFlash=true` lets it be cast any time you have priority. Qasali uses `new AllConditions(List.of(new CreatureAttackingController(), new ControlsPermanent(FOREST), new ControlsPermanent(PLAINS)))`. Gate enforced in `SpellCastingService` alt-cost validation and `CastingCostService.canPayAlternateHandCast`; flash surfaced via `CastingPermissionService.canCastWithTiming`. Forced through the evoke/`playCardWithEvoke` path (test: `castCreatureWithEvoke`). |
| Flash for a mana surcharge | `h/HarbingerOfTheTides.java` | "You may cast this spell as though it had flash if you pay {2} more" → `addCastingOption(new AlternateHandCast(List.of(new ManaCastingCost("{2}{U}{U}")), null, true))` — the surcharge is modelled as a flash-granting alternate hand cast of cost + {2}. Cast it with `castCreatureWithEvoke`. `CastingPermissionService.flashTimingRequiresAlternateCast` makes the normal-cost cast illegal outside sorcery timing, so the flash belongs to the alternate cost only. |
| ETB + discard-to-battlefield replacement | `o/ObstinateBaloth.java` | ON_SELF_DISCARDED_BY_OPPONENT `EnterBattlefieldOnDiscardEffect` + ON_ENTER_BATTLEFIELD GainLifeEffect. Replacement effect: if opponent causes you to discard this card, put it onto the battlefield instead of graveyard. ETB triggers still fire. |
